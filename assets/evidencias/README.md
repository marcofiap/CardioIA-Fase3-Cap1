# Evidencias da execucao

Salvar nesta pasta os prints usados na entrega final.

Arquivos recomendados:

- `wokwi_execucao.png`: Wokwi com ESP32 em execucao e Monitor Serial mostrando leituras.
- `wokwi_offline.png`: chave de conectividade desligada e fila offline crescendo.
- `wokwi_sync.png`: conectividade religada e sincronizacao das amostras pendentes.
- `node_red_flow.png`: fluxo importado no editor Node-RED.
- `node_red_dashboard.png`: dashboard em `http://127.0.0.1:1880/ui`.
- `alerta_dashboard.png`: dashboard exibindo alerta por BPM ou temperatura.

Esses prints atendem ao item "Prints evidenciando a aplicacao ou export do dashboard no Node-RED".
